# MASK v0.6 Offline

「AIに渡す、その前に。」をコンセプトにした、ローカル処理・オフライン対応のマスキングツールです。

## できること
- iPhone/PCの画像読み込み
- 画像上の手動黒塗り
- 日本語+英語OCR
- メール / 電話 / 郵便番号 / URL / 長い数字列の自動マスク
- マスク済みテキストのコピー
- 黒塗り済み画像の共有/保存
- PWAとしてホーム画面追加
- 初回OCRパック保存後はオフライン利用

## プライバシー設計
画像や入力文章そのものを外部サーバーへ送信するコードはありません。
OCRはTesseract.jsをブラウザ内で実行します。
初回の「オフライン準備」時のみ、Tesseract.jsのランタイムと日本語/英語OCRモデルを公開CDNからダウンロードし、Service WorkerのCache Storageへ保存します。
準備完了後のOCRは保存済みファイルだけで動作します。

## iPhoneでの使い方
1. HTTPSで公開したMASKをSafariで開く
2. オンラインの状態で「オフライン準備をする」を1回実行
3. `OCR READY`を確認
4. Safariの共有 → 「ホーム画面に追加」
5. ホーム画面のMASKから起動
6. 機内モードでも画像黒塗り / OCR / マスク / コピー / 画像共有が可能

## 重要
Service Workerは `file://` では動きません。必ずHTTPS（または開発時のlocalhost）で配信してください。
SafariのWebサイトデータを削除した場合、OCRパックも削除されるため再準備が必要です。

## OCR依存（初回のみ取得）
- Tesseract.js 5.0.0
- tesseract.js-core 5.0.0
- tessdata 4.0.0_fast: jpn / eng

## GitHub Pages版について
コネクタ経由の初回公開では、PWAアイコン画像は省略しています。機能には影響しません。iPhoneのホーム画面追加後もオフライン機能は利用できます。


## v0.5
- 通常OCR / レイアウト保持OCRを切り替え可能
- OCRは1回だけ実行し、文字座標から両方の出力を端末内で生成
- 表らしい配置を検出した場合はMarkdown表へ再構成
- 表と確定できない帳票は、横位置を残した整形テキストへフォールバック
- v0.4のOCR連動自動黒塗り、ズーム、個別マスク削除を継続


## v0.6
- 帳票・表モードを強化
- 画像の局所コントラストから横罫線・縦罫線を検出
- 表をセル領域へ分割し、罫線を除外した「セルシート」を端末内で生成
- セルシートを追加OCRして、認識結果を元の行・列へ戻してMarkdown表化
- 罫線表を検出できない場合はv0.5の文字座標ベース推定へフォールバック
- 通常OCR・自動黒塗り・手動編集・オフライン動作は従来どおり
